# Python Basics Learning Examples

This folder contains beginner-friendly Python scripts that demonstrate core programming concepts. Each file focuses on specific topics and includes practical examples you can run and see results.

## Files Overview

### 1. `01_variables_and_types.py`
**What you'll learn:**
- Variables (strings, numbers, booleans)
- Basic data types
- Mathematical operations
- String operations

**Run it:**
```bash
python3 01_variables_and_types.py
```

### 2. `02_functions.py`
**What you'll learn:**
- Creating functions
- Parameters and return values
- Default parameters
- Functions with multiple return values

**Run it:**
```bash
python3 02_functions.py
```

### 3. `03_loops.py`
**What you'll learn:**
- For loops with ranges
- For loops with lists
- While loops
- Nested loops
- Break and continue statements

**Run it:**
```bash
python3 03_loops.py
```

### 4. `04_conditionals.py`
**What you'll learn:**
- If, elif, else statements
- Multiple conditions (and/or)
- Checking membership (in/not in)
- Nested conditions
- Ternary operators

**Run it:**
```bash
python3 04_conditionals.py
```

### 5. `05_lists_and_dictionaries.py`
**What you'll learn:**
- Creating and using lists
- List methods (append, insert, pop)
- List slicing
- Creating dictionaries
- Dictionary methods and operations
- Nested data structures

**Run it:**
```bash
python3 05_lists_and_dictionaries.py
```

### 6. `06_interactive_program.py`
**What you'll learn:**
- Complete programs using all concepts
- Calculator functionality
- Quiz game logic
- Data analysis with loops and dictionaries
- Word counting algorithms

**Run it:**
```bash
python3 06_interactive_program.py
```

## How to Get Started

1. **Open Terminal/Command Prompt** in this folder
2. **Run any script** using the commands above
3. **Read the output** to see how Python processes the code
4. **Look at the code** to understand what's happening
5. **Experiment** by modifying values and running again

## Learning Tips

- **Start with file 01** and work your way through
- **Read the comments** in each file to understand the code
- **Try changing values** to see different outputs
- **Run each file multiple times** to reinforce learning
- **Don't worry about memorizing** - focus on understanding concepts

## What Each Run Will Show You

Each script will print clear output showing:
- **What concept is being demonstrated**
- **The actual values and operations**
- **Step-by-step results**
- **How Python processes your code**

Perfect for beginners to see Python in action! 🐍✨
